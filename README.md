# Merge Sort

## Description

This is merge sort, it sorts an array by dividing it into two halfs over and over untill sorting is trivial then mergeing them to sort them.

## 14. Divide and Conquer 

By divideing the problem into two parts, left and right, repeatedly, once the sub array lenght is short engough then sorting is trivial
